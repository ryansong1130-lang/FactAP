# 이 폴더에서 일할 때 지킬 규칙 (Claude Code가 자동으로 읽는 파일)

이 폴더는 고등학생 팀이 만든 **AI 답변 환각 위험도 검사 앱 FactAP** 이에요. (검사 버튼 이름: Fact TAP)
사용자가 다른 AI에게서 받은 답변이 의심스러울 때 질문, AI 답변, AI가 참고한 출처를 넣으면
환각 위험도(0~1)와 등급(문제 없음, 보통, 위험)을 계산해요.
자세한 내용은 `README.md` 와 `문서/패키지_안내.xlsx` 에 있어요. 일을 시작하기 전에 먼저 읽어 주세요.

- 환각의 정의: 사실 상충, 입력 상충, 맥락 상충. AI가 답변을 거부한 경우는 환각이 아니에요.
- 답변 유형 6개: 사실 지식형, 수치 계산형, 논리 추론형, 출처 인용형, 지문 이해형, 코드 결과형.

## 꼭 지킬 것

1. **API 키를 보지도, 쓰지도 않기.** `OPENROUTER_API_KEY` 는 환경 변수나 `.streamlit/secrets.toml` 에만 있어요.
   키 값을 읽거나 화면에 출력하거나 코드, 파일, 커밋, 로그에 쓰지 마세요. `.streamlit/secrets.toml` 은 열지 마세요.
   키가 있는지는 `python -c "from 도구 import AI_호출; print(AI_호출.키가_있나())"` 로만 확인해요.
2. **연구 결과는 그대로 두기.** `기준/`, `도구/` 의 판단 방법과 `설정.py` 의 기준값, 상위 모델, 점수 합치는 방법(가중 평균),
   기준별 중요도(3/2/1), 등급 경계(0.05, 0.25), 유형이 애매할 때 두 유형 섞기(기울기 6)는 예선 1,200개 답변으로 정하고 확인한 값이에요. 바꿔야 할 것 같으면 고치기 전에 이유를 설명하고 먼저 물어보세요.
3. **자유롭게 고쳐도 되는 것:** `앱_화면.py` (화면, 문구, 디자인, '📤 공유' 메뉴), `앱_소개.py` ('ℹ️ FactAP 소개' 메뉴 글), `.streamlit/config.toml` (화면 색),
   앱을 여닫는 파일(`앱_열기.bat`, `앱_열기_창없이.vbs`, `앱_끄기.vbs`, `바탕화면_아이콘_만들기.vbs`, `도구/창없이_실행.py`)과 새로 만드는 도우미 스크립트.
   `.vbs` 파일은 한글이 깨지지 않게 UTF-16(BOM 있음)으로, `앱_열기.bat` 는 CP949 로 저장돼 있어요. 고칠 때 같은 형식으로 저장해요.
4. **고친 뒤에는 항상 시험하기:** `python 검증/시험_모두.py` → 마지막 줄이 `전체: 통과 94개, 실패 0개` 여야 해요.
5. **비용이 드는 실행은 먼저 묻기:** `python 검증/AI_포함_검증.py` 처럼 AI를 많이 부르는 명령은 예상 호출 수를 말하고
   허락을 받은 뒤 실행해요. 처음에는 `--개수 5` 로 비용부터 확인해요.
6. **올리거나 보내면 안 되는 것:** `.streamlit/secrets.toml`, `기록/`, `검증/AI_검증_저장.jsonl`, `검증/유형섞기_저장.jsonl` (`.gitignore` 에 들어 있어요).
7. **설명은 한국어로, 고등학생이 이해할 수 있게** 쉽게 해 주세요. 한 번에 한 가지씩 고치고, 무엇을 바꿨는지 짧게 알려 주세요.
