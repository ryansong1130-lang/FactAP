# FactAP 환각 검사 패키지 (앱 담당 조원용 안내서)

앱 이름은 **FactAP**, 검사 버튼 이름은 **Fact TAP** 이에요.
사용자가 다른 AI에게서 받은 답변이 의심스러울 때 **질문, AI 답변, AI가 참고한 출처**를 넣으면
**환각 위험도(0~1)와 등급(문제 없음·보통·위험)** 을 계산하는 코드 모음이에요.
기준 하나에 파일 하나이고, 각 파일 맨 위에 **쉬운 설명**(무엇을, 왜, 어떻게, 점수, 예선 검증, 한계)이 함께 들어 있어요.

> 환각의 정의: 사실 상충, 입력 상충, 맥락 상충. AI가 답변을 거부한 경우는 환각으로 보지 않아요.

## 1. 빨리 해 보기 (명령 프롬프트에서 이 폴더로 이동한 뒤)

| 하고 싶은 것 | 명령 | API 키 |
|---|---|---|
| 모든 기준의 시험 사례 + 등급 규칙 실행 (94개) | `python 검증/시험_모두.py` | 필요 없음 |
| 예시 3개로 전체 검사 해 보기 | `python 검사_실행.py --예시` | 필요 없음 |
| 내 질문·답변 파일로 검사 | `python 검사_실행.py 질문.txt 답변.txt [출처.txt]` | 있으면 더 정확 |
| 예선 자료로 기준·등급 검증 (프로그램 기준만) | `python 검증/예선_검증.py` | 필요 없음 |
| 예선 자료로 검사 AI·웹까지 넣어 검증 | `python 검증/AI_포함_검증.py --개수 5` (먼저 5개만) | **필요** (비용 듦) |
| 두 유형 섞기가 도움이 되는지 실제 AI로 확인 | `python 검증/유형섞기_검증.py --개수 5` (먼저 5개만) | **필요** (비용 듦) |
| 앱 화면 열기 (가장 쉬운 방법, 윈도우) | `앱_열기.bat` 두 번 클릭 → 브라우저에 앱이 열려요 (처음 한 번은 설치까지 자동) | 있으면 더 정확 |
| 검은 창 없이 앱 열기 (윈도우) | `바탕화면_아이콘_만들기.vbs` 를 한 번 두 번 클릭 → 바탕화면 **FactAP** 아이콘으로 열고 **FactAP 끄기** 로 끄기 (아래 12번) | 있으면 더 정확 |
| 다른 사람과 나누기 | 인터넷에 올린 앱 오른쪽 위 **📤 공유** → 링크 복사·QR코드 (아래 12번) | Secrets 에 넣기 |
| 인터넷에 올려 링크로 열기 | Streamlit Cloud 에서 Main file path 를 `app.py` 로 (아래 11번) | Secrets 에 넣기 |
| 앱 화면 열기 | `pip install -r requirements.txt` 후 `streamlit run 앱_화면.py` | 있으면 더 정확 |
| 앱에서 검사하기 | 채팅하듯 아래 입력창에 **질문** 보내기 → **AI의 답변** 보내기 → 출처를 보내거나 **Fact TAP** (아래 10번) | 있으면 더 정확 |
| 기준 설명서 다시 만들기 | `python 기준_설명서_만들기.py` | 필요 없음 |

파이썬 3.9 이상이면 돼요. 추가 설치는 `openpyxl`(엑셀 읽기), `streamlit`(앱 화면), `segno`(공유 QR코드) 세 개뿐이에요.

> **`.py` 파일은 두 번 클릭하지 마세요.** 윈도우는 확장자(.py, .md)를 숨겨서 프로그램이 문서처럼 보여요.
> 두 번 클릭하면 내용을 보여 주지 않고 바로 실행해서, 검은 창이 잠깐 떴다가 닫혀요.
> 내용을 보려면 오른쪽 클릭 → 연결 프로그램 → 메모장(또는 VS Code)으로 열고, 실행은 위 표의 명령으로 해요.

## 3. API 키 넣기 (꼭 지킬 것)

- 키는 **코드에 쓰지 않아요.** 아래 두 방법 중 하나만 써요.
  - 명령 프롬프트: `setx OPENROUTER_API_KEY "키"` 를 실행하고, 명령 프롬프트를 닫았다가 다시 열기
  - 앱: `.streamlit/secrets.toml.예시` 를 복사해 `secrets.toml` 로 이름을 바꾸고 키를 넣기
- 키가 들어간 파일은 **다른 사람에게 보내지 않고, 깃허브에 올리지 않고, 화면 캡처·보고서에 넣지 않아요.**
  (`.gitignore` 가 `secrets.toml` 을 막아 줘요)
- OpenRouter 계정과 결제는 **보호자(성인) 명의**로 해요.
- 키가 없어도 프로그램이 멈추지 않아요. AI가 필요한 기준만 "확인 불가"가 되고 나머지는 실행돼요.

## 4. 처리 순서 (검사_실행.환각_검사)

```text
질문 + 답변 + 출처
   │
   ▼ 0단계 답변 거부 거르기 ──── 거부면 "답변 거부(환각 아님)"으로 끝
   ▼ 1단계 유형 분류 (SVM. 사용자가 고르면 그 유형. 자동 분류가 애매하면 1·2순위 두 유형으로 모두 검사)
   ▼ 2단계 그 유형 상위 3개 모델에 같은 질문 다시 묻기  ← API 키 필요
   ▼ 3단계 검사 AI 3개가 판정(JSON)                      ← API 키 필요
   ▼ 4단계 공통 기준 ①②③④ → 유형별 기준 ⑤⑥
   ▼ 5단계 점수 합치기 → 종합 위험도, 등급(문제 없음·보통·위험), 환각 종류별 위험도
                         (두 유형으로 검사했으면 1순위 확률 × 1순위 위험도 + 2순위 확률 × 2순위 위험도)
```

### 4-1. 유형이 애매할 때 두 유형 섞기 (2026-11-15)
앱에서 "로지스틱 회귀가 뭐야?"처럼 예선에 없던 질문을 넣으면, 검사 AI 3개가 모두 문제없다고 해도 '보통'이 나왔어요.
원인은 두 가지였어요.
1. **① 질문-답변 일치도의 '유형 불일치 +0.2'**: 분류기가 헷갈리면 자동으로 0.2를 더했어요.
   예선 120문항으로 교차 검증해 보니 유형 불일치는 정답 1,102개 중 67개(6.1%), 환각 68개 중 2개(2.9%), 입력 상충 14건 중 0건으로
   환각보다 정답에서 더 자주 생겼어요. 환각 신호가 아니라서 **점수에서 뺐어요** (화면에는 참고로만 보여 줘요).
2. **유형을 잘못 고르면 엉뚱한 ⑤⑥이 실행됨**: 그래서 자동 분류가 애매하면(확신도 0.5 미만) **1·2순위 유형의 ⑤⑥을 모두 실행**하고,
   두 유형으로 각각 낸 종합 위험도를 **'그 유형일 확률'로 섞어요.**
   - 1순위 확률 = 1 ÷ (1 + e^(−6 × 확신도)), 2순위 확률 = 1 − 1순위 확률. 예: 확신도 0.18 → 74% / 26%
   - 기울기 6은 예선 교차 검증에서 애매했던 답변 중 정답 유형이 1·2순위 안에 있던 102개에 가장 잘 맞는 값이에요.
   - 검사 AI에게는 두 유형의 검사 질문을 **한 번에** 물어서 AI 호출 수는 그대로예요. 다시 묻기는 1순위 유형의 상위 모델에게 해요.
   - 사용자가 유형을 직접 고르면 섞지 않아요. 끄려면 `설정.py` 의 `애매하면_두_유형_섞기 = False`.
   - 예선 자료(AI 없는 기준)로는 지금 방식과 결과가 같았어요 (애매한 114개 중 110개가 정답이라 원래 0점). 효과는 새 질문 + AI 검사로 확인해야 해요.
   - **확인 실험:** `python 검증/유형섞기_검증.py --개수 5` → 괜찮으면 `python 검증/유형섞기_검증.py` (20개, 검사 AI 120번).
     '그 질문을 빼고 학습한 분류기'의 유형으로 검사해서 처음 보는 질문처럼 만들고, 예전 방식(1순위만 + 0.2)·1순위만·두 유형 섞기·진짜 유형을
     비교해요. 결과는 `검증/유형섞기_검증_결과.xlsx` 에 저장돼요. 애매한 답변 중 환각은 4개뿐이라 주로 '정답을 잘못 경고하는지'를 봐요.

한 번 검사할 때 AI 호출 수: 다시 묻기 3번 + 검사 AI 3번 = 6번
(+ 출처를 넣었으면 ②에서 출처에 없는 문장마다 1번씩 더). 보통 1~2분 걸려요.

## 6. 모든 기준이 지키는 약속 (도구/결과.py)

모든 기준 파일에는 `검사(자료)` 함수가 있고, 같은 모양의 **자료**를 받아 같은 모양의 **결과**를 돌려줘요.
그래서 앱 화면은 기준이 몇 개든, 기준 파일을 고치든 같은 코드로 보여 줄 수 있어요.

```python
자료 = {"질문": ..., "답변": ..., "출처": ..., "유형": ...,
        "상위모델_답변들": [...], "검사AI": [...], "이전결과": {기준 이름: 결과}}

결과 = {"위험도": 0~1 또는 None, "상태": "검사함" / "해당 없음" / "확인 불가",
```

- **해당 없음**: 이 질문에는 쓸 수 없는 기준 (예: 출처를 안 넣음, 식이 없는 답변)

## 7-1. 위험도 계산과 등급 기준 (설정.py 4번)

### 종합 위험도 = 기준별 위험도의 가중 평균

```text
종합 위험도 = (기준마다 위험도 × 중요도)를 모두 더한 값 ÷ (위험도를 계산한 기준들의 중요도 합)
```

'해당 없음', '확인 불가'인 기준은 빼고 계산해요. 중요도는 **예선 결과를 보기 전에 "그 기준이 무엇과 비교해서 확인하는지"** 로 정했어요.

| 중요도 | 묶음 | 무엇과 비교하나 | 기준 | 예선에서 의심(0.3 이상)했을 때 실제 환각 |
|---|---|---|---|---|
| **3** | 직접 확인 | 프로그램이 직접 계산·실행해서 만든 정답 | 계산 재검산, 코드 직접 실행, 오류 여부·출력 형식 | 6/6 (100%) |
| **2** | 근거 대조 | 질문의 조건, 지문, 출처 글, 위키백과, 논문 DB | ①, ②, 사실 ⑤⑥, 수치 ⑥, 논리 ⑤⑥, 지문 ⑤⑥, 출처 ⑤⑥ | 13/46 (28%) |
| **1** | 간접 비교 | 다른 AI의 답변, 답변 자신 | ③ 상위 모델 답변 일치도, ④ 답변 내부 일관성 | 17/61 (28%) |

계산 예 (지문 이해형, 키 없이): ③ 0, ④ 0, 지문 근거 0.8, 핵심 누락 0 → (0×1 + 0×1 + 0.8×2 + 0×2) ÷ (1+1+2+2) = **0.27 → 위험**

### 등급

| 등급 | 종합 위험도 | 화면에 보여 줄 말 | 예선에서 이 등급에 든 답변 | 그중 실제 환각 |
|---|---|---|---|---|
| **문제 없음** | 0.05 미만 | 뚜렷한 문제를 찾지 못했어요 (환각이 없다는 보장은 아님) | 1,071개 | 38개 (**3.5%**) |
| **보통** | 0.05 이상 0.25 미만 | 의심스러운 부분이 있어요. 표시된 문장을 한 번 더 확인하세요 | 57개 | 7개 (**12.3%**) |
| **위험** | 0.25 이상 | 환각일 가능성이 높아요. 다른 자료로 꼭 확인하세요 | 42개 | 23개 (**54.8%**) |
| (전체) | | | 1,170개 | 68개 (5.8%) |

등급 앞뒤로 붙는 규칙
- 0단계에서 **답변 거부**면 등급 대신 "답변 거부(환각 아님)"으로 끝나요.
  (2026-11-14) "답변 불가", "모르겠습니다"처럼 짧은 거부도 이제 답변 거부로 봐요. 전에는 이걸 못 알아봐서 AI 검사가 입력 상충으로 잘못 냈어요.
  "글에는 그 정보가 없어서 답할 수 없습니다"처럼 글을 근거로 든 답변은 지문 문제의 정답일 수 있어서 거부로 보지 않아요.
- **결정적 기준**(계산 재검산, 코드 직접 실행, 오류 여부·출력 형식)이 1이면 최소 0.8 → 위험. 프로그램이 틀린 것을 직접 확인했는데
  평균에 묻히지 않게 하려는 안전장치예요. 예선에서 이렇게 된 답변 5개 모두 실제 환각.
- 계산한 기준이 하나도 없으면 "판단 불가".
- AI 없이 검사하면 **간이 검사**라고 표시해요. 예선에서 사실·출처형 환각 40건 중 30건은 프로그램 기준만으로는 '문제 없음'이었어요.
- 예전 방식에 있던 "기준 2개 이상이 함께 0.3 이상이면 0.6으로 올림"은 가중 평균에서는 쓰지 않아요. 여러 기준이 함께 의심하면 평균이 저절로 올라가고, 예선에서 켜도 결과가 같았어요.

왜 이렇게 정했나요?
- **가중 평균에 중요도를 둔 이유**: 확실하게 확인하는 기준이 "맞다"고 하면, 덜 확실한 기준 하나의 약한 의심은 작게 반영돼야 해요.
  예: 코드를 직접 실행해서 맞았는데 다른 AI 3개 중 1개만 다르게 답한 경우 → 0.04 (문제 없음). 예선에서 이런 답변 7개는 모두 정답이었어요.
- **3/2/1이 괜찮은지**: 의심받은 답변 106개 안에서 '환각 답변의 점수가 정답 답변보다 높을 확률'(AUC)이
  3/2/1은 0.81로, 모두 같은 중요도(0.78)와 가장 높은 값(0.79)보다 높았어요. 2/1.5/1, 4/2/1, 5/3/1로 바꿔도 0.80~0.81로 비슷했어요.
  예선 결과에 맞춰 만든 가중치(기준별 정밀도)는 다른 절반 문항에서 0.79로, 미리 정한 3/2/1(0.82)보다 낮았어요.
- **0.25**: '위험'이라고 한 답변의 **절반 넘게 실제 환각**이 되는 가장 낮은 경계예요. (0.2로 하면 49.0%, 0.25면 54.8%, 0.3이면 68.4%지만 잡는 환각이 23개에서 13개로 줄어요)
- **0.05**: 중요한 기준이 문제없다고 했는데 덜 중요한 기준 하나만 약하게 의심한 경우(위의 0.04)를 '문제 없음'에 두는 경계예요.
- 예선 문항을 홀수·짝수 번호로 나눠 따로 계산해도 순서가 같았어요 (문제 없음 3.8%·3.3% < 보통 20.8%·6.1% < 위험 58.3%·53.3%).
  다만 짝수 문항의 '보통'(6.1%)은 전체 평균과 거의 같아서, '보통'의 의미는 AI 포함 검증에서 다시 확인해야 해요.
- **예전 방식(가장 높은 값, 경계 0.3·0.6)과 비교**: 문제 없음 3.6% / 보통 13.4% / 위험 53.8%, 위험 등급에 든 환각 21개.
  가중 평균은 위험 등급에 든 환각이 23개로 2개 많고, 위험의 실제 환각 비율도 54.8%로 비슷하거나 조금 높아요.
  `설정.py` 의 `합치는_방법 = "가장 높은 값"` 으로 바꾸면 예전 방식으로 돌아가요 (등급 경계도 자동으로 바뀌어요).
- **주의**: 검사 AI·웹 기준이 빠진 결과예요. 키를 넣으면 ①② 같은 기준이 더해져서 중요도 합(분모)이 커지므로,
  `python 검증/AI_포함_검증.py` 로 0.25 경계가 그대로 괜찮은지 꼭 다시 확인해 주세요.

## 10. 고칠 때 요령

- 기준값(예: 지문 근거 0.4, 논문 같음 0.8)은 `설정.py` 에서만 바꿔요.
- 기준의 중요도를 바꾸고 싶으면 `설정.py` 의 `기준_비중` 을 고치고, `python 검증/예선_검증.py` 로 등급별 실제 환각 비율을 다시 확인해요.
- 앱을 인터넷에 공개(배포)할 때는 `app.py` 로 실행해요. `app.py` 가 `코드_실행_허용 = False` 를 자동으로 켜요 (11번). 모르는 사람이 넣은 코드를 서버에서 실행하지 않게 해 줘요.
- OpenRouter 사이트에서 API 키마다 **사용 한도(credit limit)** 를 걸어 두면, 실수로 비용이 많이 나가는 것을 막을 수 있어요.
- 기준 파일을 고친 뒤에는 `python 검증/시험_모두.py` 로 원래 되던 것이 망가지지 않았는지 확인해요.
- 새 기준을 넣고 싶으면: 비슷한 기준 파일을 복사 → `정보`와 `검사(자료)`를 고치기 → `검사_실행.py` 의 목록에 파일 이름 추가.
  새 기준의 중요도는 `설정.py` 의 `기준_비중` 에 기준 이름으로 넣어요 (직접 확인 3, 근거 대조 2, 간접 비교 1. 없으면 1).
- 기준 설명을 고쳤으면 `python 기준_설명서_만들기.py` 로 `문서/기준_설명서.md` 를 다시 만들어요.
- 앱 오른쪽 위 **'ℹ️ FactAP 소개'** 메뉴(예전 이름 '📚 우리 활동')의 글은 `앱_소개.py` 에서 고쳐요. 글만 바꾸면 되고 검사 결과에는 영향이 없어요.
  버튼 이름은 `앱_화면.py` 맨 위의 `소개_메뉴_이름` 한 줄만 바꾸면 돼요. 그 왼쪽 **'📤 공유'** 버튼 이름은 `공유_메뉴_이름` 이에요 (12번).
- 화면은 ChatGPT·Gemini·Claude 같은 **대화형 AI** 모양이에요 (`화면 버전 2026-11-15 대화형`, 왼쪽 메뉴 맨 아래에 적혀 있어요).
  - 첫 화면: "안녕하세요, FactAP이에요" 인사, FactAP 특징 4개(상위 AI 3개와 교차 확인, 위키백과·논문 대조, 기준 6개로 판정, 의심 문장 형광펜),
    **예시 카드** 4개(누르면 예시 질문·답변이 들어가서 Fact TAP만 누르면 돼요).
  - 입력: 화면 맨 아래 둥근 입력창 하나로 **질문 → AI의 답변 → 출처** 순서로 대화하듯 보내요. FactAP이 다음에 넣을 것을 물어봐요.
    출처가 없으면 **Fact TAP** 버튼을 바로 누르거나 '없음'이라고 보내요. `질문: …` 다음 줄에 `답변: …` 처럼 한꺼번에 보내도 돼요.
  - 입력창 위 작은 버튼: **🔬 정밀 검사 / ⚡ 간이 검사**(ChatGPT 의 모델 고르기처럼 검사 방법 고르기 + 남은 크레딧),
    **🏷️ 유형 자동**(답변 유형 직접 고르기), **📝 한 번에 입력**(질문·답변·출처 칸이 있는 창).
  - 결과는 **'검증 리포트'** 처럼 보여 줘요: ✓ ! ✕ 판정 도장과 세 구간 위험도 눈금,
    답변 속 문제 문장 **형광펜**(옆 작은 번호 = 찾은 기준), 기준별 **검증 항목**(통과·의심·문제·해당 없음), 의심되는 환각 종류(사실·입력·맥락 상충).
    결과 아래 **'↻ 다시 검사'**, 결과 내려받기.
  - 왼쪽 옆 메뉴(＋ 새 검사, 최근 검사), 로고는 방패 + 체크. 색은 `.streamlit/config.toml`, 모양은 `앱_화면.py` 의 `_화면_꾸미기()` 에서 바꿔요.
  - 계산 방법은 하나도 바뀌지 않았고 보여 주는 방법만 바뀌었어요.
  - 새 화면이 안 보이면 왼쪽 메뉴 맨 아래 화면 버전을 확인하세요. 예전 폴더로 열었거나, 인터넷 버전이면 GitHub 에 새 파일을 다시 올려야 해요.
  (Streamlit 의 ⋮ 메뉴에는 항목을 새로 넣을 수 없어서, ⋮ 바로 옆에 우리 메뉴 버튼을 따로 뒀어요. ⋮ 메뉴는 Print, Record screen 만 남겼어요)
- **🔬 정밀 검사 메뉴 아래쪽 'API 크레딧'** 은 OpenRouter 에 이 키의 사용 한도와 남은 금액을 물어 보여 줘요 (키 자체는 보여 주지 않아요).
  키에 사용 한도(credit limit)를 걸어 두어야 '남은 금액'이 나와요. 한도가 없는 키면 지금까지 쓴 금액만 보여요.

## 11. 인터넷에 올리기 (링크 하나로 바로 들어가기)

Streamlit Community Cloud(무료)에 FactAP을 올리면 `https://○○○.streamlit.app` 같은 링크가 생겨서, 휴대폰이나 어떤 컴퓨터에서도 설치 없이 바로 들어갈 수 있어요.

1. 깃허브(github.com)에 저장소를 만들고 이 폴더 안의 파일을 모두 올려요. **`.streamlit/secrets.toml` 은 절대 올리지 않기.**
2. share.streamlit.io 에서 깃허브로 로그인 → Create app → 저장소 선택 → **Main file path: `app.py`**
3. Advanced settings 의 **Secrets** 칸에 아래처럼 넣고 Deploy 를 눌러요. (키는 이 칸에만 넣어요)

```toml
OPENROUTER_API_KEY = "sk-or-로 시작하는 키"
DAILY_AI_LIMIT = 30        # (선택) 하루 AI 검사 한도
APP_PASSWORD = "비밀번호"   # (선택) 넣으면 비밀번호를 아는 사람만 들어와요
```

`app.py` 는 검사 방법을 바꾸지 않고 **인터넷 공개용 안전 설정**만 켜요.

| 안전 설정 | 이유 |
|---|---|
| 코드 실행 끄기 | 모르는 사람이 넣은 코드가 서버에서 실행되면 API 키를 훔쳐 갈 수도 있어요. 코드 결과형의 ⑤는 '확인 불가'가 되고 검사 AI로 판단해요 |
| 검사 기록 저장 끄기 | 사용자가 넣은 질문·답변을 서버에 쌓지 않아요 |
| 하루 AI 검사 한도 (기본 30번) | 링크가 퍼져도 하루 비용이 정해진 만큼만 나가요. 넘으면 간이 검사로 바뀌어요 |
| 접속 비밀번호 (선택) | `APP_PASSWORD` 를 넣었을 때만 물어봐요 |

배포용 키는 OpenRouter 에서 **새로 만들고 사용 한도(예: 5달러)를 걸어** 두면 가장 안전해요.

## 12. 검은 창 없이 열기, 다른 사람과 나누기 (2026-11-15)

### 12-1. 검은 창 없이 열기 (윈도우)

1. 패키지 폴더의 **`바탕화면_아이콘_만들기.vbs`** 를 한 번만 두 번 클릭해요. 바탕화면에 아이콘 2개가 생겨요.
   - **FactAP**: 두 번 클릭하면 검은 창 없이 앱이 브라우저에서 열려요. 처음 한 번은 필요한 프로그램을 설치하느라 몇 분 걸려요 (알림 창이 먼저 떠요).
   - **FactAP 끄기**: 다 쓴 뒤 두 번 클릭하면 앱이 꺼져요. 브라우저 탭만 닫으면 앱은 뒤에서 계속 켜져 있어요. 컴퓨터를 끄면 저절로 꺼져요.
2. 아이콘 없이 쓰려면 폴더 안의 `앱_열기_창없이.vbs`, `앱_끄기.vbs` 를 두 번 클릭해도 같아요.
3. 앱이 이미 켜져 있을 때 FactAP 을 다시 누르면 앱을 또 켜지 않고 브라우저만 열어요.

| 이런 모습이면 | 이렇게 해요 |
|---|---|
| "게시자를 확인할 수 없습니다" 같은 보안 경고 | 인터넷에서 받은 파일이라 떠요. **열기** 를 눌러요. 매번 뜨면 zip 파일을 압축 풀기 **전에** 오른쪽 클릭 → 속성 → 아래 **차단 해제** 체크 → 확인 후 다시 압축을 풀어요 |
| "파이썬을 찾지 못했어요" | 파이썬부터 설치해요. 설치할 때 **Add python.exe to PATH** 에 꼭 체크해요 |
| 아무 일도 안 일어나거나 "앱이 켜지지 않았어요" | `앱_열기.bat` 로 열어서 검은 창에 나오는 오류를 확인해요. 창 없이 켤 때의 글은 `기록/앱_실행_기록.txt` 에 남아요 |
| "다른 프로그램이 8501번 포트를 쓰고 있어서…" | `앱_열기.bat` 로 연 검은 창이 남아 있으면 닫아요. 그래도 안 되면 컴퓨터를 다시 시작해요 |
| 패키지 폴더를 옮겼더니 아이콘이 안 돼요 | `바탕화면_아이콘_만들기.vbs` 를 한 번 더 두 번 클릭해요 |

- 창 없이 켠 앱은 **이 컴퓨터 안에서만** 열려요 (`--server.address 127.0.0.1`). 같은 와이파이의 다른 사람이 들어올 수 없어서 안전하고, 방화벽 경고 창도 뜨지 않아요.
- `.vbs` 는 윈도우에 들어 있는 VBScript 로 실행돼요. 윈도우가 나중에 VBScript 를 없애면 이 방법이 안 될 수 있는데, 그때는 `앱_열기.bat` 를 쓰면 돼요.

### 12-2. 다른 사람과 나누기

| 방법 | 누구에게 | 어떻게 |
|---|---|---|
| **인터넷 링크** (가장 쉬움) | 선생님, 친구, 발표를 듣는 사람 누구나 | 11번대로 올린 앱의 오른쪽 위 **📤 공유** 를 눌러요. 링크를 복사해 카카오톡·문자로 보내거나, **QR코드** 를 발표 화면·포스터에 넣어요 (**QR코드 그림 내려받기**). 받는 사람은 설치 없이 휴대폰·컴퓨터에서 바로 열어요 |
| **패키지 zip** | 조원 (윈도우 + 파이썬) | 프로젝트 파일의 `환각검사_패키지.zip` 을 그대로 보내요. 받은 사람은 압축 풀기 → `바탕화면_아이콘_만들기.vbs` → **FactAP** 아이콘. 내가 쓰던 폴더를 직접 압축하면 `secrets.toml`(키)과 `기록/` 이 함께 들어가니 그렇게 보내지 않아요 |

- **누구나 열 수 있게 하기**: 깃허브 저장소를 Public 으로 만들었으면 앱도 처음부터 공개예요. Private 저장소로 올렸다면 앱이 비공개라서,
  share.streamlit.io 에서 내 앱 옆 **⋮ → Settings → Sharing** 에서 **This app is public and searchable** 로 바꿔야 다른 사람이 로그인 없이 들어와요.
- **하루 AI 검사 한도는 모든 사람이 함께 써요.** 많은 사람에게 나눌 때는 Secrets 의 `DAILY_AI_LIMIT` 을 늘릴 수 있어요.
  한도를 늘려도 배포용 키에 건 사용 한도(예: 5달러)를 넘어서는 비용이 나가지 않아요. 한도를 넘으면 간이 검사로 바뀌어요.
- **내가 넣은 질문·답변은 다른 사람에게 보이지 않아요.** 각자 화면에만 나오고, 인터넷 버전은 서버에 기록도 하지 않아요.
- **내 컴퓨터에서 연 앱**(`localhost`)의 주소는 다른 사람이 열 수 없어요. 이때 **📤 공유** 를 누르면 나누는 방법(위 표)을 알려 줘요.
  내 컴퓨터로 발표하면서 인터넷 앱의 QR코드를 보여 주고 싶으면 `.streamlit/secrets.toml` 에 `APP_URL = "https://○○○.streamlit.app"` 한 줄을 넣어요.
  (APP_URL 은 비밀이 아니라서 Streamlit Cloud 의 Secrets 칸에 넣어도 돼요. 주소를 못 찾을 때만 필요해요)
- 오랫동안 아무도 안 들어오면 인터넷 앱이 잠들어요. 링크를 받은 사람이 `This app has gone to sleep` 화면을 보면 **Yes, get this app back up!** 을 누르고 1분 기다리면 돼요.
